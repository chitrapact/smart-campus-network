# smart-campus-network
Enterprise-style campus network simulation using Cisco Packet Tracer with VLANs, routing, ACL security, SSH, and wireless integration.

## Overview
Designed and simulated a secure enterprise-style campus network using Cisco Packet Tracer.

## Features
- VLAN Segmentation
- Inter-VLAN Routing
- DHCP Configuration
- DNS and Web Server
- ACL-Based Security
- SSH Remote Management
- Port Security
- Wireless Guest Network

## Technologies Used
- Cisco Packet Tracer
- VLANs
- Router-on-a-Stick
- DHCP/DNS
- ACLs
- SSH
- Wireless Networking

## Network Topology
The network consists of:
- Router
- Core Switch
- Department Switches
- Admin, ECE, and CSE PCs
- Centralized Server
- Wireless Guest Network

## Security Features
- Department isolation using ACLs
- Secure SSH management
- Port security using sticky MAC addresses
- WPA2-secured wireless network
